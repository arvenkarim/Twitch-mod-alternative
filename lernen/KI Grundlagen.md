## Die Hierarchie
```
Artificial Intelligence (AI)      jede Technik, die "intelligentes" Verhalten nachbildet
└── Machine Learning (ML)         lernt Muster aus Daten statt fester Regeln
    └── Deep Learning (DL)        ML mit tiefen neuronalen Netzen (viele Schichten)
        └── Generative AI         erzeugt neue Inhalte (Text, Bild, Audio, Code)
            └── LLMs              große Sprachmodelle, z. B. GPT, Claude, Gemini, Llama
```

## Begriffe
| Begriff | Bedeutung |
|---|---|
| **AI** | Oberbegriff. Auch regelbasierte Systeme (if/else, Expertensysteme) zählen dazu. |
| **ML** | Das System lernt eine Funktion aus Beispielen: Eingabe → Ausgabe. |
| **Deep Learning** | Neuronale Netze mit vielen Schichten, lernen Merkmale (features) selbst. |
| **Generative AI** | Modelle, die neue Daten erzeugen, statt nur zu klassifizieren. |
| **LLM** | Large Language Model: Transformer mit Milliarden Parametern, auf riesigen Textmengen trainiert. |
| **Foundation Model** | Großes, allgemein vortrainiertes Modell, das für viele Aufgaben angepasst wird. |
| **Multimodal** | Versteht/erzeugt mehrere Datentypen (Text + Bild + Audio). |

## Narrow AI vs. General AI
- **Narrow / Weak AI**: kann eine bestimmte Aufgabenklasse (Schach, Übersetzung, Chat). Alles, was es heute gibt, gehört dazu.
- **AGI (Artificial General Intelligence)**: hypothetisch, auf menschlichem Niveau über alle Aufgaben hinweg. Existiert (noch) nicht, die Definition ist umstritten.

## Klassische Programmierung vs. ML
- **Klassisch**: Regeln + Daten → Ergebnis (der Mensch schreibt die Regeln)
- **ML**: Daten + Ergebnisse → Regeln/Modell (die Maschine findet die Regeln)

## Kurze Geschichte
- 1950 Turing-Test · 1956 Dartmouth-Konferenz: Begriff „AI“
- 1980er Expertensysteme · danach mehrere „AI Winter“
- 2012 AlexNet: Durchbruch für Deep Learning in der Bilderkennung
- 2017 Paper **„Attention Is All You Need“**: der Transformer
- 2018–2020 BERT, GPT-2, GPT-3: Scaling
- 2022 ChatGPT: LLMs werden Mainstream
- Danach: Multimodalität, Reasoning-Modelle, Agents (Tools benutzen, mehrere Schritte planen)
