## Offen, bevor es ein echter Mod ist

- [ ] OAuth-Callback: Code tauschen, State einmal verbrauchen, Tokens verschlüsselt speichern
- [ ] Echte Helix-Aufrufe für Löschen, Timeout, Ban, Chat-Modi, Kanaländerung, Token-Refresh
- [ ] EventSub-Route: Signatur, Zeitstempel, Deduplizierung, Challenge beantworten
- [ ] [[Befehle]] und Wiederholungszähler in die Verarbeitung einhängen
- [ ] Verbindungsstatus, Not-Aus und Unban im Dashboard
- [ ] Typen sind schon erweitert, Dashboard und Tests ziehen `emergencyStop` und `connection` noch nicht überall nach
- [ ] LLM nur für unsichere Fälle, Prompt strikt vom Chat getrennt
- [ ] Aufbewahrung, Export und Löschung für die DSGVO
- [ ] Testkorpus: Sarkasmus, Zitate, Slang, Mehrsprachigkeit, Belästigung, Hass, Spam, Prompt-Injection
- [ ] Rollout: Replay, Shadow, Löschen und Timeout, dann Bans. Titelvorschläge parallel nur als Vorschlag

Die Abnahme dafür steht in [[Qualität]]. Der Soll-Aufbau steht in [[Aufbau]].
